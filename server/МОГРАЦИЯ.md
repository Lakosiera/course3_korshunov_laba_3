# Мограция

## Информация

- Зайти в контенер Django

```sh
docker compose exec django sh
```

- Отобразить все миграции для модуля

```sh
python manage.py showmigrations laba_3
```

- Откатить все миграции для модуля

```sh
python manage.py migrate laba_3 zero
```

- Миграции от определенной версии для модуля

```sh
python manage.py migrate laba_3 0001_initial
```

или

```sh
python manage.py migrate laba_3 0001
```

## Модуль laba_3

1. зайти в контенер Django

```sh
docker compose exec django sh
```

2. создать миграцию

```sh
python manage.py makemigrations laba_3
```

3. выполнить миграцию

```sh
python manage.py migrate
```
